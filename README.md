# **Smart Bandwidth Monitor**

A Java-based desktop application for real-time monitoring of network bandwidth usage. It tracks download/upload speeds, total data usage, latency, and packet loss, and provides a user-friendly interface with graphical visualization using Java Swing.

---

## **Features**

* Real-time monitoring of download & upload speeds
* Displays total data usage (downloaded & uploaded)
* Tracks latency and packet loss
* Shows public IP and ISP information
* Graphical visualization of network traffic
* Cross-platform support (Windows/Linux)

---

## **Technologies Used**

* **Java**
* **Java Swing** (GUI)
* **TCP Sockets** for client–server communication
* **External API** (ipinfo.io) for public IP & ISP info

---

## **Setup Instructions**

1. Clone the repository:

   ```
   git clone https://github.com/Sujimirutikaa/Smart-Bandwidth-Monitor.git
   ```
2. Open the project in any Java IDE (IntelliJ, Eclipse, VS Code).
3. Build and run the main classes:

   * `BandwidthMonitorServer.java` (Server)
   * `BandwidthMonitorClient.java` (Client)

---

## **Usage**

* Start the **server** first.
* Launch the **client** application.
* View real-time network statistics:

  * Speeds
  * Data usage
  * Latency
  * Packet loss
* Graphs update every **2 seconds** for smooth visualization.
